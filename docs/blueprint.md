# **App Name**: Account Vanisher

## Core Features:

- Phone Number Input: A single page form with a phone number input field.
- Deletion Request Button: A 'Request Deletion' button.
- Phone Number Validation and SMS: Validate the phone number format and carrier using an external phone number validation tool.
- Confirmation Message: Display a confirmation message upon successful deletion request. Include a support contact in case of issues.

## Style Guidelines:

- Primary color: Neutral white or light gray for the background.
- Secondary color: Dark gray for text to ensure readability.
- Accent: A calming blue (#3498db) for the 'Request Deletion' button and interactive elements.
- Simple, single-column layout optimized for mobile devices.
- Use clear visual hierarchy to guide the user through the process.
- Use simple, recognizable icons for the phone number input field and confirmation messages.
- Subtle animations or transitions to provide feedback on user interactions.

## Original User Request:
create a one page website in which user enter their phone number and request to delete their account
